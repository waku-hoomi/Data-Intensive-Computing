# Week 3 作业核验记录

核验日期：2026-09-24。本记录对应修复后的源码、真实 Delta 故障测试和重新设计的全数据评估。

## 最终结论

已完成本次发现问题的修复与复测。R1、R2 两项恢复缺陷及天气零订单分组问题均通过真实 Delta 测试；E1、E2 的统计和对照方法已改正，并重新完成两轮、六次全数据运行。20 项测试全部通过，没有失败或跳过。两轮的 Gold、四个产品和六条查询均一致，存储分类全部对账。按下述检测范围，Week 3 的功能、测量和文档要求已满足。

性能结论有明确边界：第一轮天气刷新期间主机终端响应延迟明显；第二轮监控开关总耗时差为负。两轮原始值均保留，因此不把总耗时差当作已精确估计的监控成本。恢复保证仍限定于单写入者及可用的 CDF 历史。
